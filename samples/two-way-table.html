Two-Way (Cross-Tabulation) Table

The corner cell carries a diagonal split header: one label names the column axis (upper triangle) and the other names the row axis (lower triangle), separated by a corner-to-corner slash.

1. Preferred pet by gender

data-diagonal turns the first header cell into a corner cell; its own text becomes the upper label and data-diagonal-bottom the lower one.

Preferred Pet Dog Cat Other TOTAL
Girl 2 5 1 8
Boy 4 3 2 9
Total 6 8 3 17

Table 1 — a default data-diagonal slash running top-left → bottom-right.

2. Mirrored slash (data-diagonal="tr")

Setting the value to tr flips the line to run top-right → bottom-left, so the row-axis label moves to the upper-right triangle.

Table 2 — both labels given explicitly via data-diagonal-top / -bottom, slash flipped with ="tr".
