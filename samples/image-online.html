Online Images

The src below points at remote https URLs. Everything else — aspect-ratio sizing, alignment, borders, band repetition — behaves exactly like local images. Each distinct URL is downloaded once per render (a per-render cache), so reusing a URL is free.

1. Full intrinsic size (auto-capped to the page)

No width/height: the image renders at its native aspect, shrunk to the content width.

<img src="https://picsum.photos/seed/natural/600/260">

2. Width only — height follows the aspect ratio

Give only width="240"; the height is derived from the fetched image's intrinsic 600×300 ratio.

<img src="https://picsum.photos/seed/aspect/600/300" width="240">

3. Alignment

A block image honours its own text-align within the content area.

a centered and a right-aligned remote copy

4. Border and explicit box

Both dimensions fixed, with a ruled frame drawn around the downloaded image.

a bordered placement at 220×80 pt, loaded over the network
