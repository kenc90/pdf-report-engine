All New Features — Combined Demo

This document showcases all six new features in one report: hyperlinks, rich text, watermark, multi-column, gantt chart, and streaming.

1. Hyperlinks & Internal Links

External: visit the project repository.
Internal: jump to the Gantt section or back to the top.
Links are fully clickable in any PDF viewer and use doc.link() / doc.goTo() internally.

2. Rich Inline Text

Combine bold, italic, underline, highlight, red, large purple, and strikethrough in one paragraph. Nest them: bold with italic inside.

3. Watermark

Notice the diagonal SAMPLE watermark behind every page — specified by <meta name="watermark" content="SAMPLE"> in the head. It renders at 12% opacity, rotated -30°, in the background layer before all content.

4. Multi-Column Layout

The engine can distribute child blocks across N equal-width columns using column-count CSS or data-columns attributes.

Content flows into the first column until it reaches the target height (total / count), then spills into the next column.

Vertical rules between columns are optional — set via data-column-rule.

The entire multi-column block is kept atomic: it never splits across pages, ensuring visual consistency.

Three columns with a light rule between each boundary, ideal for comparison layouts or newsletter-style content.

Each column receives equal width calculated from the available space minus inter-column gaps.

This sample uses the data-columns attribute form rather than inline CSS column-count.

6. Streaming Output

The renderToStream() API returns a ReadableStream<Uint8Array> that flushes each page incrementally (with bufferPages: false), reducing peak memory for server-side rendering:

APIOutputUse case
renderToBuffer()Complete BufferOne-shot generation
renderToStream()ReadableStreamHTTP response streaming
createReport()Live PDFDocumentManual pipe / custom write

All six features are declarative: watermark via <meta>, links via <a>, rich text via inline elements, columns via CSS column-count, gantt via data-chart="gantt", streaming via the renderToStream() API.
