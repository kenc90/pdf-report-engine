CSS box polish

Background boxes accept border-radius, box-shadow and a two-stop linear-gradient(…) fill — authored straight from this HTML subset or as borderRadius / boxShadow / backgroundImage on the IR.

1. Rounded background

A paragraph whose background fill has border-radius: 10px. The rounding applies to the fill; a straight border line is never curved, and on a wrapped box only the outer top and bottom edges round (interior line junctions stay square).

2. Gradient fills

A heading bar filled with linear-gradient(to right, #1e3a8a, #38bdf8) — the gradient replaces the flat background colour.
linear-gradient(to bottom, #f8fafc, #c7d2fe) runs top-to-bottom across the whole box. Even though a wrapping paragraph is painted one line at a time, the ramp is sampled against the full box height, so it stays continuous rather than repeating per line.

Direction accepts to top/right/bottom/left or an angle (e.g. 45deg), snapped to the nearest of the four cardinal axes. Only two stops are modelled — the first and the last colour.

3. Drop shadow

This card has box-shadow: 2px 3px 6px rgba(15,47,87,0.35) — an offset-x, offset-y, blur and colour. The blur is faked with stacked translucent copies of the box silhouette, so it is a soft approximation, not a Gaussian. inset shadows and a spread radius are ignored.

4. Rounded + gradient + shadow

All three decorations on one box: a diagonal gradient fill, border-radius: 16px and a drop shadow. Corner rounding and the gradient share one clipped path, so a rounded gradient box is drawn as a single clean shape.

5. Rounded image

A raster <img> is clipped to its rounded corners and gets a shadow behind it:

Limitations in short: fills round but borders do not; gradient direction snaps to four axes with two stops; shadow blur is approximate and inset/spread are dropped; a percentage radius is read as points, so use an explicit length (or a large value that clamps to a half for a pill/circle).
