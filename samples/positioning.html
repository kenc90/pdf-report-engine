Absolute Positioning & z-index

The red APPROVED stamp, the grey corner tag, the blue side panel and the centred page footer are all removed from the document flow. They never push this paragraph down — instead each is placed at fixed page coordinates during the pagination pass.

The APPROVED stamp uses position: absolute with data-page="1", so it appears only on the first page. The corner tag and footer use position: fixed, so they repeat on every page (the footer shows the live {PAGE} / {TOTAL} tokens). The side panel is absolute with a negative z-index, painting behind the body.

Second page

Notice the APPROVED stamp is gone — it was scoped to page one — while the fixed corner tag and the running footer remain, and the footer now reads Page 2. Overlays are ideal for branding, stamps, corner page numbers and decorative background shapes that must sit at exact coordinates rather than in the reading flow.

Coordinates are absolute to the page (origin at the top-left corner). A percentage for left resolves against the page width and for top against the page height. When a positioned block has no explicit width it is measured at the remaining page width to the right of left, so long text still wraps sensibly.
