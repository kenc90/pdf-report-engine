Render a PDF in your browser

This page loads the engine as a single pre-bundled ES module (browser/pdf-report-engine.js — pdfkit's self-contained browser build baked in). Edit the constrained HTML, press Generate PDF, then flip to the PDF preview tab — a real, vector, selectable-text PDF rendered on the same page, no server and no Chromium. The sample below exercises most of the library's authoring features: a real <style> sheet, a generated table of contents, combo / 100%-stacked / waterfall charts plus the new scatter / radar / gauge / heatmap kinds and reference lines, inline <svg> drawn as real PDF paths, display: flex rows and columns, rich table cells (image, QR, sparkline and nested table), conditional formatting with colour-scale heatmaps, run highlights and links, and QR / Code 128 / EAN-13 barcodes. Edit freely.

Fonts are not required for Latin text: the sample pulls Google Fonts straight from the HTML (fetched and embedded on the client), and text with no font falls back to the standard PDF base-14 fonts. To test embedding or per-glyph CJK fallback, load a Latin .ttf/.otf and a CJK .ttf/.otf from your machine below, then type mixed text such as 陳大文 test. (A browser cannot read your installed system fonts, so you choose the files yourself.)
