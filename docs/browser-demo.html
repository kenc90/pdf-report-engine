Render a PDF in your browser

This page loads the engine as a single pre-bundled ES module (browser/pdf-report-engine.js — pdfkit's self-contained browser build baked in). Edit the constrained HTML on the left, press Generate PDF, and the real, vector, selectable-text PDF renders on the right — no server, no Chromium.

Fonts are not required for Latin text: with none selected the engine falls back to the standard PDF base-14 fonts. To test embedding or per-glyph CJK fallback, load a Latin .ttf/.otf and a CJK .ttf/.otf from your machine below, then type mixed text such as 何小鵬 test. (A browser cannot read your installed system fonts, so you choose the files yourself.)
