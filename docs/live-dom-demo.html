Live DOM → PDF

Choose an example to see what the browser DOM adapter can capture. It reads the selected element's current content and computed styles, then hands them to the report engine. The page JavaScript is not rerun by the converter.

Expect a report, not a screenshot. Text stays selectable and the report engine paginates it. Supported styles translate well; unsupported browser layout and generated content may be lost. The tabs below include both good fits and deliberate limitations.

Explicit header and footer · good fit

The report body is captured from this element. Separate HTML strings provide repeating page bands, including per-page number tokens.

const report = htmlElementToReportDoc(reportElement, {
  page: { size: 'a5', margin: 36 },
  header: '<div style="font-size:9px;font-weight:bold;color:#174a73;border-bottom:1px solid #dbe5ef;padding-bottom:6px">NORTHWIND STUDIO · OPERATIONS</div>',
  footer: '<div style="font-size:8px;color:#586c80;text-align:right;border-top:1px solid #dbe5ef;padding-top:5px">Confidential · Page {PAGE} of {TOTAL}</div>',
});
