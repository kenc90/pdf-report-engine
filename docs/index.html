Why this, and not HTML→PDF?

Most "HTML to PDF" tools drive a headless browser and screenshot the page — the result is an image, text is not selectable, and pagination is an afterthought. pdf-report-engine lays out, line-breaks, paginates and embeds glyphs in-process, emitting true vector text. It is built for reports: repeated column headers, group breaks, subtotals, running page numbers, and band-based page headers/footers.

Features

Authoring & pagination

Describe a report as data or simple markup and the engine lays it out, breaks lines and paginates it — with repeating headers, group totals and page numbers, just like a classic reporting tool.

Styling & layout

A familiar CSS look: real selectors and a modern box model, including rounded corners, soft shadows and gradient fills — all still crisp vector output.

Tables & conditional formatting

Rich, report-grade tables that merge cells, hold images or charts inside a cell, and recolour rows and cells based on their values.

Charts & vector graphics

A full range of charts plus scalable graphics, images and barcodes — everything drawn as real vector geometry, sharp at any zoom.

Navigation & branding

Long documents stay easy to move through with bookmarks, a table of contents and clickable links, and you can stamp a watermark across every page.

Output & security

Get the finished PDF as a buffer or a stream, and add passwords and usage permissions when a report needs to be protected.

See them together: samples/dashboard.html is a single report with stylesheet selectors, a translucent watermark, a clickable TOC, bar / stacked bar / line / area / pie / donut charts, QR / Code 128 / EAN-13 codes, highlights and internal links. The newer depth features have focused samples: rich-cells.html, conditional-format.html, color-scale.html and chart-depth.html (combo / 100% / waterfall); svg-flex.html shows inline <svg>, a .svg <img>, a display: flex row and the new radar / gauge / heatmap / scatter chart kinds; and box-polish.html demonstrates rounded, gradient-filled and shadowed boxes.

How it works

Two entry points funnel through one pipeline:

authoring (IR or HTML)  →  ReportDoc IR  →  layout  →  pagination  →  pdfkit writer  →  PDF bytes
  • renderToBuffer(report, options?) — one-shot: IR in, PDF bytes out.
  • renderToStream(report, options?) — returns a ReadableStream for incremental delivery.
  • createReport(report, options?) — the live pdfkit doc plus the paginated pages model, so you can stream yourself.

60-second taste

import fs from 'node:fs';
import { renderToBuffer } from 'pdf-report-engine';

const report = {
  info: { title: 'Hello, PDF' },
  page: { size: 'a4', margin: 56 },
  style: { fontFamily: 'Helvetica', fontSize: 11 },
  body: [
    { type: 'heading', level: 1, content: 'Quarterly Snapshot' },
    { type: 'paragraph', content: 'Built entirely in JavaScript — no browser.' },
  ],
};

const pdf = await renderToBuffer(report);
fs.writeFileSync('report.pdf', pdf);
